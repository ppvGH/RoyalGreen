# Asset provenance and licensing

Runtime assets under `res/` are unchanged from the original RoyalGreen repository.
Their original historical commits are retained. Attribution/licensing metadata
is incomplete; the owner has been asked to identify self-created and external
assets before a public binary release. No ownership or license is invented.

The root project currently has no project license; this development work does
not choose one on the owner's behalf. Publicly visible source is not evidence
of permission for arbitrary redistribution. Upstream library license notices
are included in staged packages under `third-party/`.

| Asset group | Source to confirm |
| --- | --- |
| OBJ/MTL models (`res/meshes`) | Original Blender/export author and any imported components |
| Player/cat sprite sheets and projectile/life textures | Original creator/download location and license |
| Room textures and game background | Original creator/download location and license |
| GLSL shaders (`res/shaders`) | Author and any tutorial-derived code |

The package can be built and validated locally while this inventory is being
completed. No GitHub release/tag is published by the packaging script.
